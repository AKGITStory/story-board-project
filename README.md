# Story Board Project

Turn sound recordings and images into text, give each one a heading, and set its priority.

## What's here

| Folder | What it is |
|---|---|
| `web/story-priority-board.html` | The Story Priority Board: Task screen (sound + image to text), Load text files, Set priorities. |
| `web/sound-image-notes.html` | The standalone Sound & Image Notes screen, with a button to the board. |
| `local-app/` | A Python app that runs on your computer and transcribes sound and reads images automatically. See `local-app/README.md`. |

## Live pages (claude.ai)

- Story Priority Board: https://claude.ai/artifact/3ZksjztaieiTAuMYL3ej6p
- Sound & Image Notes: https://claude.ai/artifact/7kEzG4icQag1R3FRJr5t3z
